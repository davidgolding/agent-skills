# Critical Text Collation - Interactions

## Interaction Rules

When the user requests a collation task or wants to run the skill:

1. **Ask for the target folder**: Prompt the user to provide the directory containing the `.docx` transcription documents.
2. **Clarify witness naming**: Confirm how columns should be labeled (e.g. using the document filename or a custom short name/siglum).
3. **Handle custom formatting instructions**: Ask if there are specific rich-text schemas or highlight colors the user wants to apply to variants.
4. **Identify custom alignment options**: Ask if the user wants to group lines/verses by specific markers (like headings or verse numbers) or use the automatic sentence segmentation.
5. **Confirm and present a plan**: Always list the identified files and the proposed output spreadsheet path before starting the collation, requesting explicit user approval.
