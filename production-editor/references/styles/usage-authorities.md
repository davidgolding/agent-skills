# Usage Authorities

What each usage/grammar authority is for, and how to cite it. Pick per project at intake; default is GMEU + CGG.

- **GMEU -- Garner's Modern English Usage.** American usage: word choice, idiom, confusable pairs, register, the Language-Change Index. Citation: `(GMEU, "entry name")`, e.g. `(GMEU, "contemporary; contemporaneous")`.
- **CGG -- Bryan A. Garner, *The Chicago Guide to Grammar, Usage, and Punctuation*.** Grammar and punctuation: sentence structure, word forms, syntax, agreement, punctuation mechanics. Citation: `(CGG, "Topic," section_number)`, e.g. `(CGG, "Pronouns: case," 5.12)`.
- **Fowler's Dictionary of Modern English Usage.** British usage counterpart to GMEU; use when the project's dialect is UK English. Citation: `(Fowler, "entry name")`.
- **Merriam-Webster.** American spelling and definition authority--the default dictionary for US-dialect spelling calls not otherwise settled by the style manual or style sheet. Citation: `(MW, "entry")`.
- **American Heritage Dictionary.** Alternate American spelling/definition authority, sometimes preferred for its usage notes. Citation: `(AHD, "entry")`.
- **Words into Type.** Older but still-cited production-conventions reference (typesetting-adjacent mechanical calls not covered by the primary style manual). Citation: `(WIT, "topic")`.

Cite a grammar ruling only to a grammar authority, and a usage ruling only to a usage authority--see `references/citation-protocol.md` rule 2.
