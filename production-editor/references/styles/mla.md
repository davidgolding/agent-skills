# MLA (9th ed.)

Condensed guidance for mechanical/copy/reference passes; the manual governs.

- **Serial comma:** yes.
- **Quotation marks:** double for first-level, single for nested. Commas/periods inside closing quotes; colons/semicolons outside.
- **Dashes:** em dash for breaks/asides; en dash rare (used in some ranges); MLA prose favors sparing dash use compared to Chicago.
- **Numbers:** spell out numbers expressible in one or two words; use numerals otherwise, and always for measurements/statistics/dates/times.
- **Dates/time:** day month year ("5 March 2026") is MLA's preferred order in works-cited entries; either order acceptable in running prose if consistent.
- **Capitalization:** headline-style (title case) for titles of works.
- **Abbreviations:** minimize in prose; standard abbreviations permitted in citations (e.g., "p.," "vol.," "ed.").
- **Italics:** titles of standalone works; MLA does not italicize for mere emphasis.
- **Citation architecture:** in-text parenthetical `(Author page)`, no comma between author and page. Full Works Cited entry, alphabetized by author (or title if no author), using the nine core elements. Locator format: `(MLA 9, Works Cited)`, or a section number only when confirmed present in the loaded manual.
