# Editor's Style Sheet

This file is the skill's persistent record of settled editorial decisions. It is shared across every manuscript this skill touches, so decisions are scoped per project--treat a ruling from one project as applying only to that project.

Read the active project's section before every pass. A settled entry is binding; treat it as final rather than re-litigating it. Append new decisions as they're settled, with their authority. If a manual and a settled style-sheet entry conflict, surface it to the user rather than resolving it silently. Keep entries confined to their own project section.
